# Solar Battery Charger with Automatic Solar Tracking

## Overview
This project is designed to maximize solar energy collection by automatically tracking the position of the sun. The system adjusts the solar panel angle throughout the day, improving charging efficiency.

## Features
- Automatic solar tracking
- Battery charging system
- Efficient solar energy utilization
- Low power consumption
- Cost-effective design

## Components Used
- Arduino Uno
- Servo Motor
- LDR Sensors
- Solar Panel
- Rechargeable Battery
- Charge Controller
- Connecting Wires

## Working Principle
Two LDR sensors detect sunlight intensity. The Arduino compares both sensor values and rotates the servo motor toward the brighter side. The solar panel remains aligned with the sun, producing maximum power to charge the battery.
